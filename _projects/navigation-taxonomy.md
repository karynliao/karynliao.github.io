summary: People struggled to find recipes in a very large library. I found out why and helped restructure the navigation around how users actually think.
role: UX researcher
methods: IA audit, tree sort study, path analysis
team: Content strategy, design
challenge_title: Plenty of content, hard to find
challenge: Analytics and support feedback showed frustration while browsing, but the cause was unclear.
approach_title: Let users sort it
approach: After an audit of the existing structure, I ran a tree sort study with target users and analyzed thousands of sorting decisions. The navigation turned out to follow internal logic rather than users' mental models.
impact:
  - Simpler categories, merged duplicate labels, and names in users' own words.
  - The revised navigation shipped before launch.
  - Set a precedent for structuring content around user behavior.
